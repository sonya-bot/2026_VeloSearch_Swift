# 録音・モニタリング

## 共通仕様

RecordingsとMonitoringsは共通の録音Controllerを使用します。

- サンプルレート：44,100 Hz
- チャンネル：Automatic、MonoまたはStereo
- ビット深度：16-bit
- フォーマット：Linear PCM WAV
- 品質：High
- 入力：iPhone内蔵マイクまたは接続デバイス
- マイク面：前面または背面
- 指向性：Stereo polar pattern

両画面は共通のAudio I/O表示と開始／停止ボタンを使用します。保存先はすべての計測タブで
共通のScene選択部品から指定します。縦横画面ともSettings以外では画面全体をスクロールせずに
確認できるレイアウトを前提とします。

録音中は0.01秒間隔で経過時間、0.05秒間隔でL/Rメーターを更新します。メーター表示は
-60 dBから0 dBを0.0から1.0へ正規化しています。

## マイクと端末向き

Settingsで次を指定します。

- マイク：背面または前面
- 端末向き：縦または横

内蔵マイクでは対象data sourceと端末向きを反映します。Stereo選択時はStereo polar patternと
2チャンネル入力を要求し、接続デバイスでは成立したL/Rを使用します。

要求したチャンネル数に対応していない場合、録音は開始しません。保存後にも実ファイルの
チャンネル数を検査し、不一致の場合はWAVを削除します。

## Recordings

### 操作

1. 保存先としてDefaultまたはSceneを選択します。
2. 円形の録音ボタンを押して開始します。
3. 停止ボタンを押して終了します。

保存名は次の形式です。

```text
Recording_yyyyMMdd_NN.wav
```

`NN`は保存先フォルダ、接頭辞、日付ごとの連番です。

## Monitorings

Settingsでモニタリング機能をONにすると、RecordingsタブがMonitoringsへ切り替わります。

### 操作

1. モニタリングをONにします。
2. 再生出力とテスト音源を選択します。
3. 保存先としてDefaultまたはSceneを選択します。
4. 録音ボタンを押します。

実行回数は1〜99回で指定できます。各タームは3秒カウントダウン後に音源を1回再生し、再生時間が
経過すると録音も自動停止します。次のタームへは3秒後に自動遷移し、手動停止も可能です。

反復自体を示す専用ファイル名やサブフォルダは作りません。1タームを通常の1回実行と同じ単位で
保存し、各タームに日付別連番を割り当てます。実行中は保存先、方向タグ、反復回数を変更できません。

保存名は次の形式です。

```text
Monitoring_yyyyMMdd_NN.wav
```

## 再生出力

- iPhone本体：`.defaultToSpeaker`を使用します。
- 接続デバイス：Bluetooth A2DPを許可し、強制スピーカー出力を解除します。

接続デバイスが外れても設定値は維持し、次回開始時に利用不可として表示します。

## 同梱テスト音源

- スイープ信号5秒
- スイープ信号10秒
- スイープ信号30秒
- 猫の鳴き声
- ビープ音

`sweep.wav`もResourcesに含まれますが、現在の選択肢は秒数付きスイープを使用します。

次の音源定義は互換性のため残していますが、対応ファイルがないため選択画面には表示しません。

- ピンクノイズ：`pink_noise.wav`
- ホワイトノイズ：`white_noise.wav`
- 1 kHzサイン波：`sine_1k.wav`

過去の設定値として残っている場合は、スイープ信号5秒へ戻します。

## 現在の制約

- Bluetooth出力時の実際の入力チャンネル構成は端末と接続機器に依存します。
- Simulatorでは実機と同じマイク構成を検証できないため、ステレオ録音は実機で確認してください。
