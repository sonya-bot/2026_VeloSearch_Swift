# 録音・モニタリング

## 共通仕様

RecordingsとMonitoringsは共通の録音Controllerを使用します。

- サンプルレート：44,100 Hz
- チャンネル：2
- ビット深度：16-bit
- フォーマット：Linear PCM WAV
- 品質：High
- 入力：iPhone内蔵マイク
- マイク面：前面または背面
- 指向性：Stereo polar pattern

録音中は0.01秒間隔で経過時間、0.05秒間隔でL/Rメーターを更新します。メーター表示は
-60 dBから0 dBを0.0から1.0へ正規化しています。

## マイクと端末向き

Settingsで次を指定します。

- マイク：背面または前面
- 端末向き：縦または横

内蔵マイクの対象data sourceを選び、Stereo polar patternを設定した後に2チャンネル入力を
要求します。端末向きはマイク選択後にAVAudioSessionへ反映します。

ステレオ入力に対応していない場合、録音は開始しません。保存後にも実ファイルの
チャンネル数を検査し、2チャンネルでない場合はWAVを削除して
`ステレオ録音未成立`を3秒間表示します。

## Recordings

### 操作

1. 保存先としてDefaultまたはSceneを選択します。
2. 円形の録音ボタンを押して開始します。
3. 停止ボタンを押して終了します。

保存名は次の形式です。

```text
Recording_yyyyMMdd_NN.wav
```

`NN`は保存先フォルダ、接頭辞、日付ごとの連番です。

## Monitorings

Settingsでモニタリング機能をONにすると、RecordingsタブがMonitoringsへ切り替わります。

### 操作

1. モニタリングをONにします。
2. 再生出力とテスト音源を選択します。
3. 保存先としてDefaultまたはSceneを選択します。
4. 録音ボタンを押します。

録音開始後にテスト音源を1回再生し、音源の再生時間が経過すると録音も自動停止します。
手動停止も可能です。

保存名は次の形式です。

```text
Monitoring_yyyyMMdd_NN.wav
```

## 再生出力

- iPhone本体：`.defaultToSpeaker`を使用します。
- 接続デバイス：Bluetooth A2DPを許可し、強制スピーカー出力を解除します。

接続デバイスが外された場合、設定画面では本体／スピーカーへ戻します。

## 同梱テスト音源

- スイープ信号5秒
- スイープ信号10秒
- スイープ信号30秒
- 猫の鳴き声
- ビープ音

`sweep.wav`もResourcesに含まれますが、現在の選択肢は秒数付きスイープを使用します。

次の選択肢はUIに存在しますが、対応ファイルは現在同梱されていません。

- ピンクノイズ：`pink_noise.wav`
- ホワイトノイズ：`white_noise.wav`
- 1 kHzサイン波：`sine_1k.wav`

これらを選択した場合、プレビューまたは録音開始時に音源が見つからない旨をログへ記録します。

## 現在の制約

- 入力デバイス選択はUserDefaultsへ保存されますが、録音処理は内蔵マイクを選択します。
- Bluetooth出力時の実際の入力チャンネル構成は端末と接続機器に依存します。
- Simulatorでは実機と同じマイク構成を検証できないため、ステレオ録音は実機で確認してください。
