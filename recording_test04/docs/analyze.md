# 音響特性測定

## 概要

Analyze画面は指数スイープ信号（ESS）を実行時に生成しながら入力音声を録音し、チャンネルごとの
インパルス応答（IR）と周波数応答を算出します。Analyzeは独立した計測タブで、Collectionsより
左に配置します。生成条件は同梱`sweep_30s.wav`と揃え、同じ生成サンプルを再生と解析基準に
使用します。

## 操作

1. Settingsで共通のAudio I/Oを設定します。
2. Analyzeで保存先、方向タグ、実行回数を選択します。
3. `Start`を押すと3秒のカウントダウン後に測定を開始します。
4. 測定後に解析と結果保存を行います。
5. 複数回指定した場合は3秒後に次のタームへ自動遷移します。

実行回数は1〜99回です。実行中は保存先、方向タグ、実行回数を変更できません。`Stop`を押すと
現在のシーケンスを中断します。

反復を示す専用ファイル名やサブフォルダは作成しません。1タームを単独実行1回と同じ扱いにし、
保存先と日付に応じた通常の連番を割り当てます。

## ESS測定条件

| 項目                     |        値 |
| ------------------------ | --------: |
| 開始周波数               |     20 Hz |
| 終了周波数               | 20,000 Hz |
| スイープ時間             |      30秒 |
| スイープ前無音           |       1秒 |
| スイープ後無音           |       1秒 |
| 最大振幅                 |      0.95 |
| フェードイン／アウト     |      なし |
| ターム開始カウントダウン |       3秒 |
| ターム間隔               |       3秒 |

同梱WAVは44.1 kHz、mono、Float32、全長32秒です。Analyze内生成では不要なリサンプリングを
避けるため、周波数範囲、時間、振幅、無音時間、フェード条件を同梱版と揃えたうえで、実行時の
Audio Sessionのサンプルレートを使用します。録音形式がStereoの場合は2段、Monoの場合は1段で
波形を表示します。

## 解析

録音信号と生成したESSを周波数領域でデコンボリューションし、チャンネルごとに次を求めます。

- インパルス応答
- 20 Hzから、サンプルレートのNyquist周波数または20 kHzまでの周波数応答
- 480点の対数周波数サンプル
- 1 kHz基準の正規化応答
- 1/12オクターブ平滑化応答

表示とCSVには1 kHzを0 dBとしたraw値と、その1/12オクターブ平滑値を使用します。録音ピークが
約-1 dBFS以上の場合はクリッピング警告を表示します。

## チャンネル表示

- iPhone内蔵入力かつStereo：`Back + Bottom`または`Front + Bottom`
- 外部入力かつStereo：`L / R`
- Mono：`Mono`

回転方向はアプリ内で判定しません。方向タグはDetectings／Monitorings／Analyzeで共有し、
測定結果との対応付けとして保存します。

## 保存ファイル

各タームは同じbasenameを持つ次のファイルを保存します。

```text
Analyze_yyyyMMdd_NN.wav
Analyze_yyyyMMdd_NN.csv
Analyze_yyyyMMdd_NN.json
Analyze_yyyyMMdd_NN_IR_CH1.wav
Analyze_yyyyMMdd_NN_IR_CH2.wav
```

Monoの場合は入力経路が2チャンネルを維持していても録音時に1チャンネルへ変換し、IRをCH1だけ
保存します。Stereoの場合は成立した2チャンネルからCH1、CH2のIRを保存します。

### 周波数応答CSV

先頭列は`frequency_hz`です。チャンネルごとに次の2列を追加します。

```text
chN_raw_db
chN_smoothed_db
```

### JSONメタデータ

次を記録します。

- フォーマットバージョンと測定方式
- 方向タグ
- サンプルレート、チャンネル数、チャンネルラベル
- ESSの開始／終了周波数、スイープ時間、前後無音時間
- 正規化周波数と表示平滑化方式
- 実際の入力・出力デバイス名

## 表示とレイアウト

- Audio I/O、保存先、方向タグ、実行回数を他の計測タブと同じ位置関係で表示します。
- 縦画面では波形、周波数応答、状態、操作ボタンをスクロールせずに表示します。
- 横画面では左側に状態と操作、右側にAudio I/O、設定、波形、周波数応答を配置します。
- Audio I/Oモーダルは他の計測タブと共通の表示専用コンポーネントです。

## グラフの拡大表示

測定完了後、各音量波形または音響特性グラフを個別にタップすると、それぞれを全画面表示します。
測定中または表示対象のデータがない場合は拡大できません。

### 音量波形

- StereoではCH1／CH2、MonoではCH1を個別に開きます。
- 横軸は時間（秒）、縦軸は正規化振幅（FS）です。
- 横軸は測定時間を5点、縦軸は`+1.0`から`-1.0`まで5点の目盛りで表示します。
- グラフ上をタップまたはドラッグすると、選択位置の時間と振幅を表示します。

### 音響特性グラフ

- 横軸は20 Hz〜20 kHzの対数周波数、縦軸は1 kHz基準の相対レベル（dB）です。
- 周波数は20、50、100、200、500 Hz、1、2、5、10、20 kHzに目盛りを表示します。
- レベルは+24 dBから-48 dBまで12 dB刻みで表示します。
- グラフ上をタップまたはドラッグすると、選択周波数と各チャンネルの平滑化レベルを表示します。
